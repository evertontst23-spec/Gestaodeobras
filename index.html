Cadastre a digital deste funcionário em Funcionários → 👆 Digital antes de usar o leitor.
Como configurar o leitor USB:
1. Conecte o leitor USB HID ao computador ou tablet
2. Em Funcionários, clique em 👆 Digital para cada trabalhador
3. Peça para o funcionário encostar o dedo — o código é salvo automaticamente
4. Na próxima entrega de EPI, use este botão para autenticar
